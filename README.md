# Zoro for Android
1. Create a new GitHub repo and upload everything in this folder (including the hidden .github folder).
2. Open the repo > Actions > "Build APK" > wait about 3 minutes > download the Zoro-APK artifact.
3. Unzip it, copy app-debug.apk to your phone, tap it, and allow "install unknown apps".
4. Open Zoro and allow the microphone.
